# Portfolio

Este repositório contém o código fonte do meu portfólio pessoal, desenvolvido com React e Vite. O objetivo deste projeto é apresentar minhas habilidades em desenvolvimento web de forma visualmente atraente e interativa, utilizando as melhores práticas e ferramentas modernas do ecossistema JavaScript.

## 🌐 Visualize o Projeto

Você pode acessar o meu portfólio online através do seguinte link:  
[https://giuseppefilippin.github.io/Portfolio](https://giuseppefilippin.github.io/Portfolio)

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **React**: Biblioteca JavaScript para criação de interfaces de usuário dinâmicas e reativas.
- **Vite**: Ferramenta de build rápida e moderna para projetos baseados em JavaScript, que proporciona uma experiência de desenvolvimento ágil.
- **React Router**: Para navegação entre as páginas do portfólio sem recarregar a página.
- **Tailwind css**: Estilização dos componentes do portfólio.
- **GitHub Pages**: Para a hospedagem do portfólio de maneira simples e eficiente.

## 📂 Estrutura do Projeto

A estrutura do repositório é organizada da seguinte maneira:

- `public/`: Contém os arquivos estáticos que são servidos diretamente pela aplicação, como o `index.html` e as imagens.
- `src/`: Contém o código fonte do aplicativo React.
  - `components/`: Componentes reutilizáveis como cabeçalhos, rodapés e seções de conteúdo.
  - `assets/`: Imagens e outros arquivos estáticos utilizados no site.
  - `App.js`: Componente principal do React que renderiza as seções do portfólio.
  - `index.js`: Ponto de entrada do aplicativo, onde o React é inicializado.
- `package.json`: Gerencia as dependências do projeto e os scripts de execução.
- `vite.config.js`: Configurações do Vite para otimizar o processo de build e desenvolvimento.

## 🛠️ Como Rodar o Projeto Localmente

Para rodar o projeto em seu ambiente local, siga os passos abaixo:

1. **Clone este repositório**:
    ```bash
    git clone https://github.com/giuseppefilippin/Portfolio.git
    ```

2. **Navegue até o diretório do projeto**:
    ```bash
    cd Portfolio
    ```

3. **Instale as dependências**:
    ```bash
    npm install
    ```

4. **Inicie o servidor de desenvolvimento**:
    ```bash
    npm run dev
    ```

5. **Abra o navegador e acesse o projeto**:
    Acesse o endereço localhost para visualizar o portfólio localmente.
